# AGENTS.md

This folder is the start of a learning app for lernapps.net. It has no app yet. A person without technical knowledge
(usually a teacher) opened it in a codespace and wants an app built. Talk to them in German, in plain language.

## First session

1. Ask which app they want: topic, grade, and what learners do. One question at a time.
2. Choose a short name for the folder and the app: lower case, letters and hyphens (for example `bruchrechnen`).
3. Run, in this folder, once: `npx --yes @lernapps/tooling init <short name>`.
4. It replaces this file with the rules of every lernapps app. Read the new `AGENTS.md` completely and follow it from
   there.

Never run `lernapps create` before the person confirmed the plan, as the new `AGENTS.md` says.
